# 🔐 Cipher Launcher

**Cipher Launcher** is a small, clean Android launcher designed for **watches and tiny Android devices**.

The idea is simple: instead of giving you a cramped phone-style launcher, Cipher gives you a **watch-first experience** with a PIN-protected launcher when you actually need your apps. ⌚✨

## ✨ What makes Cipher different?

Cipher has **two separate PINs**, so one device can have two completely different experiences:

### ⌚ Watch Mode
A minimal watch experience with:

- 🕒 Large 12-hour clock (with optional seconds)
- 📅 Date
- 👟 Live step count
- 🔋 Live battery level
- 🖤 AMOLED-friendly black UI

### 🏠 Launcher Mode
Your normal Android environment, adapted for a small screen:

- 🕒 Home screen with live time and date
- 👟 Steps + battery at a glance
- 👆 **Swipe up** to open the app drawer
- 🔎 Search installed apps
- 📱 Launch your Android apps
- ⚙️ Settings and launcher controls
- 🖼️ Custom wallpaper support
- 👁️ Option to hide the Cipher branding

Your **Watch PIN** and **Launcher PIN** are different on purpose.

## 🔓 How it works

When Cipher is locked, you get a simple clock screen.

**Swipe up** → PIN screen → enter your PIN.

Your PIN decides where you go:

`Watch PIN` → ⌚ Watch Mode  
`Launcher PIN` → 🏠 Full Launcher

The launcher also locks again when the app leaves the foreground, so the private launcher isn't meant to stay open after you leave it. 🔒

## 👆 Simple gestures

Cipher is designed around a few easy gestures:

- **Lock screen → Swipe up:** open PIN keypad
- **Home → Swipe up:** open app drawer
- **App drawer → Press Back:** return home
- **Watch Mode → Long press:** return to the lock screen
- **Back button:** returns within Cipher without intentionally closing the launcher
- **Home → Long press:** open Settings

No complicated gesture system — just the stuff that makes sense on a tiny display. :)

## 🎨 Settings

Tweak Cipher from **Settings**:

- **AMOLED black** — pure black surfaces for OLED watches
- **Seconds** — show seconds on the watch face
- **Hide branding** — remove the Cipher logotype from the home screen
- **Wallpaper** — pick a custom wallpaper from your images, or remove it

## 🎨 Built for small screens

Cipher keeps the interface intentionally minimal:

- 🌑 Dark / AMOLED-friendly UI
- 🖼️ Wallpaper support with a readability scrim
- 🎯 Large touch targets
- ✨ Minimal typography
- 📱 App drawer instead of cramming every app onto the home screen
- 🔐 PINs stored as salted password hashes

## 📱 Compatibility

Cipher Launcher supports:

**Android 7.0+ (API 24)**

On Android 10 and newer, Android requires the `ACTIVITY_RECOGNITION` permission for step counting, so Cipher asks for that permission when needed.

## 🚀 Getting started

1. Install Cipher Launcher.
2. Set a **Watch PIN** and a **Launcher PIN**.
3. Set Cipher as your default Home app when Android asks.
4. You're ready. ⌚
