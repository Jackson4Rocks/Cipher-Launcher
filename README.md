# 🔐 Cipher Launcher

A small, clean Android launcher built for **watches and tiny Android devices**. Cipher is watch-first by default, with a PIN-protected launcher you reach only when you actually need your apps. ⌚✨

## ✨ Two PINs, two experiences

Cipher uses **two separate PINs** — one for Watch Mode, one for the full Launcher — so they stay completely independent.

### ⌚ Watch Mode
A minimal, glanceable watch face:
- 🕒 Large 12-hour clock (optional seconds)
- 📅 Date
- 👟 Live step count
- 🔋 Live battery level
- 🖤 AMOLED-friendly black UI

### 🏠 Launcher Mode
Your Android apps, adapted for a small screen:
- 🕒 Home screen with live time and date
- 👟 Steps + battery at a glance
- 👆 **Swipe up** to open the app drawer
- 🔎 Search installed apps
- 📱 Launch your Android apps
- ⚙️ Settings and launcher controls
- 🖼️ Custom wallpaper support
- 👁️ Option to hide the Cipher branding

## 🔓 How it works

When locked, Cipher shows a simple clock screen.

**Swipe up** → PIN screen → enter your PIN.

Your PIN decides where you go:

`Watch PIN` → ⌚ Watch Mode  
`Launcher PIN` → 🏠 Full Launcher

Cipher locks again when it leaves the foreground, so your private launcher doesn't stay open after you walk away. 🔒

## 👆 Gestures

- **Lock screen → Swipe up:** open PIN keypad
- **Home → Swipe up:** open app drawer
- **App drawer → Back:** return home
- **Watch Mode → Long press:** return to lock screen
- **Home → Long press:** open Settings
- **Back button:** navigate within Cipher without closing it

## 🎨 Settings

- **AMOLED black** — pure black surfaces for OLED screens
- **Seconds** — show seconds on the watch face
- **Hide branding** — remove the Cipher logotype from the home screen
- **Wallpaper** — pick a custom wallpaper, or remove it

## 🎨 Built for small screens

- 🌑 Dark / AMOLED-friendly UI
- 🖼️ Wallpaper support with a readability scrim
- 🎯 Large touch targets
- ✨ Minimal typography
- 📱 App drawer instead of cramming every app onto the home screen
- 🔐 PINs stored as salted password hashes

## 📱 Compatibility

**Android 7.0+ (API 24)**

On Android 10+, the `ACTIVITY_RECOGNITION` permission is required for step counting; Cipher requests it when needed.

## 🚀 Getting started

1. Install Cipher Launcher.
2. Set a **Watch PIN** and a **Launcher PIN**.
3. Set Cipher as your default Home app when prompted.
4. You're ready. ⌚
